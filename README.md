# 🛋️ RentZa

A full-stack clone of **Rentomojo**, an online furniture rental platform that allows users to rent home furnishing products such as beds, wardrobes, sofas, TV units, study tables, and other household essentials. The application provides a seamless browsing and shopping experience with authentication, product management, cart functionality, and secure checkout.

## 🚀 Project Objective

The objective of this project was to build a full-stack furniture rental platform that replicates the core functionality of Rentomojo. The project focuses on implementing user authentication, product browsing, search and filtering, cart management, and backend API development while following modern web development practices.

# ⚙️ Setup & Installation

## Clone the repository

```bash
git clone https://github.com/<your-username>/<repository-name>.git
```

Move into the project directory

```bash
cd <repository-name>
```

---

## Install Dependencies

```bash
npm install
```

---

## Configure Environment Variables

Create a `.env` file in the root directory.

```env
PORT=5000

MONGODB_URL=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```

---

## Run the Backend

```bash
npm run server
```

---

## Run the Frontend

Open `index.html` using Live Server

or

```bash
npm start
```
